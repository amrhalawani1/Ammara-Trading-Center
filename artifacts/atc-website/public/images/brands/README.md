Partner brand logos for the homepage grid.

One file per brand, named by the brand's catalogue slug:
  barazza.svg  blum.svg  dnd.svg  emuca.svg  fgv.svg  grass.svg  hafele.svg
  hawa.svg  hettich.svg  kessebohmer.svg  salice.svg  vibo.svg

Any colour works: the tile renders the file as a mask in its own text colour, so only the shape
matters. Avoid files with a background rectangle (it would render as a solid block). Until a file exists the
tile shows the brand name as a wordmark instead.
